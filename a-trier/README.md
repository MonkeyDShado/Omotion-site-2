# Dépôt des fichiers

Déposez ici vos visuels et vidéos, tels quels. Claude les optimise, les range au bon endroit puis vide ce dossier.

Depuis un téléphone : sur github.com, ouvrez ce dossier, puis « Add file » → « Upload files ».
Limite : 25 Mo par fichier. Au-delà, envoyez plutôt un lien (WeTransfer, Google Drive…).
